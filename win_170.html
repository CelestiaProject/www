Celestia 1.7.0 installation on Windows

Celestia 1.7.0 is still under active development, meaning you may encounter bugs, performance issues, crashes, and incomplete features. This is a nightly build, so be sure to check back regularly for updates.

  • Celestia 1.7.0 for x64 based Windows Systems (345 MB)
    This version will run on any computer with an x86-64 type CPU.
  • Celestia 1.7.0 for x86 based Windows Systems (332 MB)
    This version will run on any computer with either an x86 or x86-64 type CPU.
